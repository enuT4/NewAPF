# NewAPF

ProjectAPF를 리팩토링한 개인 프로젝트입니다.

## Project

여러 미니게임을 플레이하며 기록을 세우고 점수를 경쟁하는 모바일 게임입니다.

기존 ProjectAPF에서 발견한 구조와 성능 문제를 개선하는 것을 목표로
게임 시스템과 UI 구조를 재설계했습니다.

## Tech Stack

- Unity
- C#
- PlayFab

## 주요 구현 및 개선

- 시간 기반 재화 충전 시스템 개선
- Object Pooling 적용
- UI 구조 개선
- 사운드 시스템 개선
